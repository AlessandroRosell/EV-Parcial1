
# Evaluacion Parcial 1 - Machine Learning

----------

### Caso 3: Análisis de popularidad en canciones de Spotify

----------

### Descripcion del proyecto

Este proyecto se basara en analizar las caracteristicas y metadatos del conjunto de datos proporcionado por el profesor para
predecir la popularidad de las canciones mediante un algoritmo de aprendizaje supervisado hecho con Scikit-learn

----------

### Recursos y/o librerias a usar

- Python 3.10+
- Pandas / Numpy
- Matplotlib / Seaborn
- Scikit-Learn
- Github Codespaces & Jupyter Notebooks
